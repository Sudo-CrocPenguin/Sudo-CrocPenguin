## Sobre mí

Soy desarrollador de software en Medellín, estudiante de **Tecnología en Desarrollo de Software** en la Universidad Católica Luis Amigó y **aprendiz de desarrollo en IAS Software**. Me enfoco en el **backend** y en la **infraestructura**: diseño APIs con arquitecturas claras, modelo bases de datos normalizadas y despliego en servidores Ubuntu que administro yo mismo, con Nginx, SSL y SSH endurecido.

Como freelancer en Workana he construido y desplegado **más de 30 sitios** para restaurantes, firmas legales, e-commerce e instituciones, lo que me dio un hábito que aplico en todo: hacerme cargo del ciclo completo, desde el modelado del dominio hasta que el sistema está en producción y monitoreado.

- **Ingeniería de software:** MVVM + Repository, arquitectura en capas, Clean Architecture y diseño guiado por historias de usuario.
- **Full stack:** Spring Boot, Node.js/TypeScript y FastAPI en el backend; React, React Native y Kotlin en el cliente.
- **Seguridad aplicada:** JWT, Argon2, AES-256-GCM y OAuth 2.0 en proyectos reales.
- **Mentalidad de producto:** priorizo lo que el usuario necesita y elijo la arquitectura por el dominio, no por moda.

**Abierto a:** colaboración en proyectos backend, código abierto, proyectos freelance web y oportunidades para seguir creciendo como desarrollador.

## Proyectos destacados

<details>
<summary><b>Adulto Funcional</b> — Plataforma full stack con Clean Architecture</summary>
<br/>

Aplicación web y móvil construida sobre un backend en Spring Boot 3 con Clean Architecture, autenticación propia y migraciones versionadas.

| Aspecto | Detalle |
|:--|:--|
| **Stack** | Spring Boot 3 · MariaDB · Flyway · React · React Native |
| **Escala** | Backend único que sirve a cliente web y cliente móvil |
| **Rendimiento** | Esquema versionado con Flyway para despliegues reproducibles |
| **Seguridad** | JWT para sesiones, Argon2 para contraseñas |
| **Impacto** | Dominio desacoplado de frameworks y fácil de probar |
| **Repositorio** | [Ver repositorio](https://github.com/Sudo-CrocPenguin/Adulto-Funcional) |

Separa estrictamente dominio, casos de uso e infraestructura, de modo que la lógica de negocio no depende de la base de datos ni del framework web.

</details>

| Aspecto | Detalle |
|:--|:--|
| **Stack** | Node.js · TypeScript · Express · PostgreSQL · Prisma |
| **Escala** | Diseñado para gestionar múltiples cuentas conectadas |
| **Rendimiento** | Acceso a datos tipado con Prisma sobre PostgreSQL |
| **Seguridad** | OAuth 2.0 y tokens cifrados con AES-256-GCM en reposo |
| **Impacto** | Elimina tareas manuales repetitivas sobre el correo |
| **Repositorio** | [Ver repositorio](https://github.com/Sudo-CrocPenguin/Auto-Gmail-code) |

El enfoque principal fue el manejo seguro de credenciales de terceros: nunca se almacenan tokens en texto plano.

</details>
